# Студия развития детей «ТалантЛэнд» (Красноярск)

Официальный сайт и интерактивная панель управления (CMS) для детской студии английского языка «ТалантЛэнд» (педагог Анастасия Онищук).

## 🌟 Основные разделы
- **Главный экран (Hero):** продающее УТП, живые метрики и рейтинг 5.0 на 2ГИС
- **Видео с уроков:** реальные видеозаписи занятий в мини-группах
- **Тарифы и программы:** 3 формата обучения с прозрачными ценами
- **Квесты и сценарии:** игровые методики (игры с куклами, бинго, детективные квесты)
- **Преподаватель:** карточка Анастасии Онищук с дипломами и регалиями
- **Фотогалерея студии:** 8 фотографий с лайтбоксом
- **Отзывы:** проверенные отзывы родителей с 2ГИС
- **Всплывающая форма:** удобная модальная запись на пробное занятие без якорных скачков
- **Панель управления (CMS):** личный кабинет для настройки цен, акций, фото и просмотра CRM-заявок

## 🚀 Запуск
Сайт полностью статичен. Достаточно открыть index.html в любом браузере или подключить GitHub Pages.
